Fractal studies

A few Mandelbrot and Julia sets generated with Python.

Python · NumPy · Matplotlib

Each pixel begins a sequence of complex numbers. I color it by how long the sequence stays within an escape radius. These are a few results I kept from changing the starting points, constants, and colors. Select an image to see it at full size.

The rule behind them

Both images come from repeating the same operation:

\[z_{n+1}=z_n^2+c.\]

For the Mandelbrot set, I start at \(z_0=0\) and let each pixel choose \(c\). For a Julia set, I hold \(c\) fixed and let each pixel choose \(z_0\). A small change in \(c\) can change the whole picture.

For the Mandelbrot set, the core of the Python generator is an escape-time loop:

for step in range(num_iter):
    active = np.abs(z) < radius
    z[active] = z[active] ** 2 + c[active]
    escape_time[active] += 1

Points that stay within the radius longer receive a different color.
